# Changelog

All notable changes to the Polar Glass skin are documented here.

## [1.1.0] - 2026-11-25

### Added
- **Avatar only** variant (`PolarGlass-AvatarOnly.xzp`): shows your avatar and hides the disc panel.
- **LB / RB** is now the first item in the Home button-hint bar.

### Fixed
- Text no longer cut off at the bottom: the Settings menu, the top status line, profile and disc names, the rating, button hints, and every other label (52 boxes in all).
- Loading screen: the status line no longer draws two messages on top of each other.
- Home button hints fit every Aurora language, including Brazilian Portuguese, with no overlap and nothing running off the screen.
- The empty avatar circle now hides when the profile panel is turned off.

### Removed
- "LB / RB page" text under the game count (LB / RB moved to the hint bar).

Thanks to u/uchiha_saskito for the detailed report and photos.

## [1.0.0] - 2026-10-12

### Added
- First public release of the **Polar Glass** skin (`PolarGlass.xzp`, revision 1) for Aurora 0.7b.
- Companion **Polar Glass** CoverFlow layout (`Polar Glass.cfljson`).
